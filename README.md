# StudyTimeCalculator
A simple C# console application for calculating total study time.

## Features

* Takes multiple study sessions as input in minutes
* Calculates the total study time
* Converts total minutes into hours and minutes

## Example

```text
How many times?
4

Enter the number 1 in minutes:
45
Enter the number 2 in minutes:
80
Enter the number 3 in minutes:
35
Enter the number 4 in minutes:
50

The Total is: 3:30
```

## Technologies

* C#
* .NET

## Future Improvements

This project is a simple first version. Future versions may include better time input, input validation, and additional study-time tracking features.
